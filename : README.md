# SauceDemo Manual Testing Project

## Project Overview

This project demonstrates a complete manual testing workflow for the SauceDemo web application using Jira and GitHub.

## Testing Approach

- Manual functional testing
- Positive and negative testing
- Test case creation and execution
- Checkout and order flow testing
- Test result documentation
- Jira Agile/Scrum workflow

## Tools Used

- **Jira** – Agile/Scrum project management and test activity tracking
- **GitHub** – Test documentation and project version control
- **SauceDemo** – Application under test

## Testing Performed

- Valid login
- Invalid username
- Invalid password
- Product and cart functionality
- Checkout validation
- Successful order completion
